Folder na lokalne kafelki XYZ wygenerowane w QGIS.
Po wygenerowaniu umieść tu podfoldery {z}/{x}/{y}.png (lub .jpg/.webp).
Następnie utwórz plik config.json według config.example.json z enabled=true,
poprawnym extension i maxZoom.

Nie dodawaj do GitHub danych prywatnych ani ortofotomapy bez prawa publikacji.
